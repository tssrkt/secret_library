# Переключение библиотек

Без параметра URL открывается «Моя библиотека». Параметр `?library=<UID участника>` выбирает библиотеку друга; выбор сохраняется при перезагрузке и поддерживает Back/Forward. Email не используется как идентификатор вкладки или публичное имя.

Вкладки друзей доступны только при действующем входящем разрешении и наличии опубликованного каталога. При отзыве или отсутствии доступа чужой каталог очищается, а интерфейс предлагает вернуться в свою библиотеку. Поздний ответ предыдущей загрузки не должен подменять текущую библиотеку.

Каждое переключение заново создаёт штатный каталог и поиск, сбрасывает запрос, фильтры и пагинацию. Обновление и переиндексация доступны при просмотре своей библиотеки; настройки папок относятся к владельцу текущего аккаунта.

## Доступ к каталогу друга

Личный каталог владельца остаётся в его Google Drive. Для просмотра другом публикуется ограниченная проекция разрешённой части каталога. В неё попадают только папки, которые владелец разрешил показывать, и их потомки. Файлы непосредственно в корне не включаются автоматически.

Личные настройки, диагностические данные, данные восстановления индекса и приватные файлы обложек не становятся частью публичной проекции. Скачивание исходной книги требует, чтобы текущий Google-пользователь имел доступ к самому файлу; разрешение внутри приложения не выдаёт дополнительных прав на исходный файл.

При изменении разрешённых папок прежняя публикация перестаёт считаться действующей до завершения обновления. Новая версия становится доступной после успешной публикации. Доступ к старым версиям ограничен.

## Проверка актуальности доступа

Состояние доступа должно проверяться по действующему отношению владельца и получателя, а не считаться постоянным только потому, что участник ранее появился в списке друзей. После смены корневой папки или изменения разрешённых папок опубликованный каталог и отметка доступа должны соответствовать текущему состоянию.

## Конфигурация

Клиентская конфигурация приложения подключена к используемому проекту. Для работы социальных функций включены Google Authentication и необходимые правила доступа. Публикация каталога выполняется приложением при обновлении личной библиотеки и изменении разрешённых папок.

## Проверки

Браузерные проверки охватывают собственный каталог по умолчанию, переключение библиотек, URL/reload, отзыв доступа, поздние ответы, поиск, пагинацию, клавиатурную навигацию и мобильное взаимодействие.

Проверки правил доступа запускаются через Firestore Emulator. На 2026-11-18 полный Node-набор дал 222 успешных теста, 0 ошибок и 2 ожидаемых пропуска; браузерный smoke — 231 успешную проверку, Playwright E2E — 8 успешных проверок.
