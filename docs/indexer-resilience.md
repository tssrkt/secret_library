# Ограниченная устойчивость индексатора

Оригиналы на Drive не изменяются. Полный строгий XML parse остаётся основным
путём; временная копия с пустыми повреждёнными binary проверяется тем же parser.
Полноценные XML-теги внутри предполагаемого payload считаются неоднозначными
границами. Случайные `<A`, `<!` и управляющие байты сами по себе тегами не являются.
В журнале сохраняются количество кандидатов, результат и безопасная причина
отказа recovery, encoding и контейнер. Payload и фрагменты книги не записываются.

Копия реального «07. Кровь Кадии.fb2» в рабочем каталоге не обнаружена.
Тест воспроизводит известный тип дефекта, включая ложные начала тегов и raw
control characters; это не подтверждение проверки конкретного оригинала.

## Кодировки и description

`TextDecoder` выбирается по BOM, UTF-16 byte pattern или XML declaration.
Поддерживаются стандартные browser aliases и дополнительный `windows1252`.
Legacy encoding сама по себе не создаёт warning.
Справочник поведения: [WHATWG Encoding](https://encoding.spec.whatwg.org/).

Range-чтение растёт до 64 KiB, 256 KiB, 1, 2, 4, 8, 16, 32, 64, 128 MiB.
Диапазоны не перекрываются; конец известного файла ограничивает запрос.
Полный ответ 200 используется локально, включая обложку и строгую проверку,
без второй полной загрузки. `description_missing` означает отсутствие description
в полном документе; `description_scan_limit_exceeded` — достижение бюджета чтения.
У полного raw FB2 также есть бюджет 128 MiB перед созданием XML/DOM.

## ZIP: бюджеты браузера

Старые 16 MiB compressed / 32 MiB uncompressed были ограничениями памяти,
а не признаками повреждённого FB2. Теперь в `config.js` явно заданы:

| Проверка | Бюджет |
|---|---:|
| Сжатые данные выбранной записи | 64 MiB |
| Распакованный FB2 | 128 MiB |
| Суммарный заявленный объём всех записей | 512 MiB |
| Количество записей | 4096 |
| Степень сжатия записи и архива | 500:1 |
| Центральный каталог | 4 MiB |

Это конечные консервативные бюджеты, а не измеренный максимум реальной библиотеки:
локального отчёта с размерами всех отказавших архивов нет. Тест содержит валидный
Deflate FB2 больше 32 MiB со сжатым размером больше 16 MiB.

Проверки выполняются до распаковки. Распаковывается только выбранный FB2.
`DecompressionStream` последовательно заполняет один заранее ограниченный
выходной буфер; длина сверяется с central directory на каждом chunk и в конце.
При превышении/ошибке поток отменяется. Большие записи (>32 MiB входа или выхода)
не распаковываются и не парсятся параллельно друг с другом. Малые задачи могут
продолжаться в пределах существующего лимита конкурентности индексатора.

Байтовые буферы выбранной большой записи занимают максимум 192 MiB, дополнительно
нужны decoded string и DOM. Полностью потоковый metadata-only parse не добавлен:
DOMParser требует полный документ, а отбрасывание хвоста скрыло бы ошибки XML.
Контракт API: [WHATWG Compression](https://compression.spec.whatwg.org/).

Превышения имеют отдельные safety codes; это не утверждение о повреждении книги.
Неправильные размеры/Deflate остаются `malformed_zip`, отсутствие FB2 — `zip_no_fb2`.

## Проверка без полного rebuild

После обновления достаточно «Повторить ошибки»: новые decoder/parser/ZIP пути
применяются к прежнему failed set. Успешные записи выходят из failed, binary recovery
учитывается как recovered; настоящие ошибки остаются. Полный rebuild сохранён.
Автотест использует этот же retry pipeline с подставленными загрузками, без Drive.
