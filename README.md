# Тайная библиотека

«Тайная библиотека» — веб-приложение для личной библиотеки книг в Google Drive и обмена доступом к выбранным библиотекам с приглашёнными участниками.

## Возможности

- Вход через Google и выбор корневой папки личной библиотеки.
- Обход вложенных папок и построение каталога книг.
- Поддержка FB2, EPUB, MOBI и ZIP с книгами внутри архивов.
- Извлечение метаданных, аннотаций и обложек там, где формат и файл это позволяют.
- Обновление каталога при добавлении, изменении и удалении книг.
- Возобновление прерванной индексации и отдельный повтор ошибок.
- Поиск и фильтрация книг.
- Приглашения по электронной почте, регистрация приглашённых участников и список друзей.
- Обмен доступом к библиотекам и выбор доступных папок.
- Просмотр опубликованных библиотек друзей с проверкой действующего разрешения.
- Настройки личной библиотеки и управление корневой папкой.

## Поддерживаемые форматы и ограничения

Кандидатами для каталога считаются файлы FB2, EPUB, MOBI и ZIP. ZIP поддерживает поиск вложенных книг в папках архива. Для ZIP применяются ограничения размера и поддерживаемых методов сжатия. ZIP64, многотомные и зашифрованные ZIP, RAR и 7z не поддерживаются.

Приложение предназначено для работы в браузере с подключённым Google-аккаунтом и доступом к Google Drive. Это не читалка книг и не offline/PWA-приложение.

## Запуск

Для локального запуска из корня репозитория:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/. Запуск через `file://` не поддерживается.

Публичная версия: https://tssrkt.github.io/secret_library/

## Тесты для разработчиков

Установите зависимости командой `npm ci`.

- `npm run test:social` — проверки правил доступа с локальным эмулятором.
- `npm run test:e2e` — браузерные end-to-end проверки Playwright.
- `node tests/search-keyboard.mjs` — браузерный smoke-набор (нужен установленный браузер и настроенное окружение).
- `node --test tests/apps-script-invite.test.mjs` — тесты логики почтовых приглашений.

Полный актуальный снимок проверок и известные ограничения записаны в [отчёте передачи проекта](docs/PROJECT_HANDOFF.md). Успешное выполнение локальных тестов само по себе не заменяет проверку живого Google-входа и доступа к реальной библиотеке.
